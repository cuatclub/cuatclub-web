Colors

Core semantic tokens, defined once in globals.css and exposed as Tailwind utilities (bg-primary, text-foreground-muted, …).

Tag palette

Nine hues, each with a solid + light-background pair, used for club category tags. Colors arrive as data (API-provided hex), not fixed Tailwind classes.

Typography

Body typeface is IBM Plex Sans Thai (font-ibm-plex) everywhere in the component library. Sarabun is loaded but not yet used by any component. Almost every text role follows the same two-step responsive scale: smaller below md, larger from md up.

Shadow & radius

One shadow token in the whole system — a soft, wide, low-opacity ambient lift used for every elevated surface. Radius follows a small/interactive vs. large/container hierarchy.

Buttons

Two cva variants. Fixed 40px height. Recreated here class-for-class from Button.tsx.

Form fields

Every field shares the same states: default border → hover (primary-light) → focus (primary), or entirely swapped to error. Border color is the focus indicator — no visible ring.
