## User Story
As a visitor, I want to view a club's detail page with its description, photos, and contact links, so that I can learn more about the club and reach out through their social media.

## Description
Users need a dedicated page showing full details for a single club, matching the Figma design . The page shows the club's logo, name, affiliation, category tags, an about section, a gallery of club photos that can be viewed, and contact channels that link out to the club's social media.

## Scope
- Club detail page layout matching the Figma design
- Back navigation control
- Header section: club logo, name, affiliation, category tags
- "About" (เกี่ยวกับ) section with club description text
- Photo gallery section showing club atmosphere photos, viewable by the user (e.g. clickable to enlarge)
- "Contact" (ช่องทางติดต่อ) section listing social channels (e.g. Instagram, Facebook, TikTok, Line), each clickable and linking out to the corresponding social media profile

## Acceptance Criteria
- Navigating to a club's detail page displays that club's logo, name, affiliation, and category tags
- The about section displays the club's full description text
- The gallery displays the club's photos, and clicking a photo lets the user view it (e.g. enlarged/full view)
- Each contact channel is displayed as a clickable item and opens the corresponding social media link in a new tab
- Clicking back navigates the user back to the previous page (e.g. club list)
- Page is viewable without requiring login, consistent with the public club list page

## Out of Scope
- Editing club details from this page
- Club detail data management/API (assumed to already exist or be covered separately)
